# Runbook — запобіжник гостьових позик (Етап 10, крок 10f.1)

Джерело: [execution plan Етапу 10, §7.3](../plan/stage-10-real-world-history.md#73-технічний-запобіжник-до-зняття-t9).

> **D2 — відкритий release blocker.** Запобіжник його **не знімає** і **не гарантує**, що введені дані
> синтетичні: код не відрізняє реальну людину від синтетичної. **Реальні персональні дані гостя
> (ім'я, аліас, email, контакти) заборонені в усіх середовищах** — development, test, staging і
> production. Цю заборону тримає Product Owner організаційно.

## Конфігурація

| Змінна                       | За замовчуванням | Значення                                  |
| ---------------------------- | ---------------- | ----------------------------------------- |
| `GUEST_LOANS_ENABLED`        | `false`          | рівно `true` або `false`                  |
| `GUEST_LOANS_SYNTHETIC_ONLY` | `false`          | рівно `true` або `false`                  |

Перевірка — `apps/api/src/config/env.validation.ts`, fail-fast на старті. Значення `1`, `0`, `yes`,
`TRUE`, порожній рядок, пробіли — помилка (`Некоректне оточення`).

| Середовище                  | `ENABLED` | `SYNTHETIC_ONLY`      | Результат                            |
| --------------------------- | --------- | --------------------- | ------------------------------------ |
| будь-яке                    | не задано / `false` | будь-яке    | функція вимкнена                     |
| `production`                | `true`    | будь-яке              | **API не стартує**                   |
| не-`production`             | `true`    | не задано / `false`   | **API не стартує**                   |
| не-`production`             | `true`    | `true`                | функція увімкнена (лише тестові дані) |

`production` — це `NODE_ENV=production`. Середовища beta (Етап 11) теж мають `NODE_ENV=production`.

## Що робить API при вимкненій функції

`GuestLoansEnabledGuard` (`apps/api/src/common/guest-loans-enabled.guard.ts`) відповідає
`403` із `code: FEATURE_DISABLED` до виконання сесійного guard'а, handler'а, сервісів і запитів до БД.
Guard має стояти **першим** у `@UseGuards(...)`. Гостьових маршрутів у 10f.1 ще немає; чинні
позики між зареєстрованими користувачами запобіжник не зачіпає.

Доступність функції для UI (`GET /auth/session`) не додано: UI гостьових позик з'явиться в 10f.2.

## Зняття запобіжника

Лише після виконання **всіх** критеріїв §7.2 плану й письмового рішення PO, окремою зміною коду
(`GUEST_LOANS_PRODUCTION_ALLOWED`). Зміною змінних оточення запобіжник не знімається.
